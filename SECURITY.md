# Security

If you find a vulnerability in Vitalgate or any of its repositories, please report it privately: email **franciscastillodev@proton.me**, or use [GitHub's private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the affected repository. Please don't open a public issue.

Include what you found, how to reproduce it, and its impact. You'll get a reply within 3 working days, and credit in the fix if you'd like it.
