### Performance budgets for every pull request

Vitalgate runs Lighthouse on each pull request and fails its check when a change breaks your budgets, so a slow page never reaches production.

<img src="https://vitalgate.vercel.app/demo/vitalgate-demo.gif" width="640" alt="A pull request deploys, the Vitalgate check fails on a broken budget, a fix lands and every budget passes">

[Website](https://vitalgate.vercel.app) · [Core Web Vitals checker](https://vitalgate.vercel.app/tools/core-web-vitals) · [Pricing](https://vitalgate.vercel.app/pricing) · [Free for open source](https://vitalgate.vercel.app/open-source)

</div>

- **A check on every pull request.** Budgets for LCP, CLS, FCP, TBT and the Lighthouse score, the median of three runs, on your own GitHub Actions runner or against your Vercel, Netlify or Render preview.
- **Results where you review code.** A comment with every metric against its budget and your baseline, and a check you can make required.
- **Real users too.** INP, LCP and CLS from the Chrome UX Report for your live site.
- **Alerts where your team works.** Email, Slack, Discord, Microsoft Teams, Google Chat or a webhook, plus Linear and Jira issues for failing pull requests.
